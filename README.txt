미쿠지 노트 / Mikuji Note

구성: index.html(자판기), guide.html, guide-ja.html, guide-en.html(3개 언어 가이드), about.html, about-ja.html, about-en.html(3개 언어 소개 및 개인정보), editorial.css, 이미지 파일.

실행: 압축을 풀고 폴더 안에서 다음 명령을 실행하세요.
  python3 -m http.server 3000
그 후 브라우저에서 http://localhost:3000 을 열어주세요.
웹 호스팅에 올릴 때는 모든 파일을 같은 폴더에 업로드하세요.

글꼴은 Google Fonts에서 불러오므로 인터넷 연결이 필요하며, 연결되지 않으면 기기의 기본 폰트로 표시됩니다.
현재 버전에는 운세 보관함 기능이 없습니다. 광고와 실제 결제는 연결되어 있지 않습니다.
문의 이메일은 Japan Onsen Stay에서 공개한 주소를 참고했습니다. 운영 정보와 개인정보 처리방침은 공개 전 실제 운영 환경에 맞게 검토해야 합니다.
