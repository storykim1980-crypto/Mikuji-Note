일본 파워스폿 여행 / 日本のパワースポット巡り / Japan’s Sacred Places
희망 도메인: japansacred.com (구매 및 연결 여부 별도 확인)
오미쿠지 체험: 미쿠지 노트 / Mikuji Note

사이트 구성
- index.html: 한국어·일본어·영어 오미쿠지 자판기 및 메인 화면
- places.html, places-ja.html, places-en.html: 3개 언어 파워스폿 가이드 (전국 30곳)
- guide.html, guide-ja.html, guide-en.html: 3개 언어 오미쿠지 가이드
- about.html, about-ja.html, about-en.html: 3개 언어 소개 및 개인정보 안내
- editorial.css, places.css, *.webp: 디자인 및 이미지 파일

미리 확인하기
압축을 풀고 해당 폴더에서 아래 명령을 실행한 뒤 http://localhost:3000 을 열어 주세요.
  python3 -m http.server 3000

서버에 올릴 때
1. 기존 서버 파일을 먼저 백업하세요. 이 자료는 기존 사이트와 비교하거나 서버에 적용한 상태가 아닙니다.
2. 사이트를 새로 공개할 폴더의 웹 문서 루트에 압축파일 자체가 아니라 압축을 푼 전체 파일을 함께 업로드합니다. 하위 폴더를 추가하지 말고 같은 위치에 두어야 상대 경로가 맞습니다.
3. 다른 사이트가 같은 폴더에 있다면 index.html 등이 덮어쓰여 그 사이트가 바뀔 수 있습니다. 기존 폴더와 도메인 연결을 확인하고 필요한 경우 별도 웹 루트를 사용하세요. 관련 없는 기존 파일을 임의로 삭제하지 마세요.
4. 도메인 구입·DNS·HTTPS와 웹 호스팅 설정은 별도로 필요합니다. 업로드 후 실제 도메인에서 세 언어, 파워스폿·가이드 링크, 이미지, 음악 및 운세 동작을 확인하세요. 이전 화면이 보이면 캐시도 확인하세요.
5. 실제 호스팅·로그·광고·분석 서비스에 맞게 세 언어의 개인정보 안내를 공개 전에 검토·수정하세요. 이 패키지는 결제 및 광고를 연결하지 않았습니다.

Google Fonts를 사용하므로 인터넷 연결이 필요하며, 연결되지 않으면 기기의 기본 글꼴로 표시됩니다. 브라우저 정책상 음악 자동재생이 차단되면 이용자의 첫 조작 이후 시작될 수 있습니다. 운세 보관함과 실제 결제 기능은 없습니다.

배경 음악은 사이트 내 Web Audio로 연주되는 창작 합성 음악입니다. 별도의 음원 파일이 필요하지 않습니다.
